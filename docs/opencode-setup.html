OpenCode setup

Connect OpenCode to the central mtel-skill-resolver MCP server as a remote server.

1. Edit config

Add an entry under mcp in opencode.json at the repo root (create it if missing). Keeping it in the project file scopes the server to this repo — and it can be committed for the whole team. Do not use the global ~/.config/opencode/opencode.json:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mtel-skill-resolver": {
      "type": "remote",
      "url": "https://mcp-registry.internal.company.com/mcp",
      "enabled": true
    }
  }
}

2. With auth token

If the server sets MCP_AUTH_TOKEN, add the bearer header:

{
  "mcp": {
    "mtel-skill-resolver": {
      "type": "remote",
      "url": "https://mcp-registry.internal.company.com/mcp",
      "enabled": true,
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
OpenCode does have an opencode mcp add --url … --header … CLI command, but it always writes to the global ~/.config/opencode/opencode.json — even when run from inside a repo, and there is no project-scope flag. So for repo-scoped setup, edit the project opencode.json by hand as above; don't use opencode mcp add.

3. Verify

Restart OpenCode. The resolve_skills tool from mtel-skill-resolver appears in the available tools list. Run /mcp in the TUI to confirm the server connected.
