OpenCode setup

Connect OpenCode to the central mtel-skill-resolver MCP server as a remote server.

1. Edit config

Add an entry under mcp in opencode.json (project root) or ~/.config/opencode/opencode.json (global):

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mtel-skill-resolver": {
      "type": "remote",
      "url": "https://mcp-registry.internal.company.com/mcp",
      "enabled": true
    }
  }
}

2. With auth token

If the server sets MCP_AUTH_TOKEN, add the bearer header:

{
  "mcp": {
    "mtel-skill-resolver": {
      "type": "remote",
      "url": "https://mcp-registry.internal.company.com/mcp",
      "enabled": true,
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}

3. Verify

Restart OpenCode. The resolve_skills tool from mtel-skill-resolver appears in the available tools list. Run /mcp in the TUI to confirm the server connected.

Use "type": "local" with a command array instead if you want each machine to spawn resolver/index.js over stdio rather than hitting the central HTTP server.
