Claude Code setup

Connect Claude Code to the central mtel-skill-resolver MCP server.

1. Add the server

Run this from the repo root. --scope project writes to a .mcp.json at the repo root so the server is scoped to this repo (and can be committed for the whole team):

claude mcp add --transport http --scope project \
  mtel-skill-resolver https://mcp-registry.internal.company.com/mcp

If the server is protected with MCP_AUTH_TOKEN, pass the bearer header:

claude mcp add --transport http --scope project \
  --header "Authorization: Bearer <token>" \
  mtel-skill-resolver https://mcp-registry.internal.company.com/mcp

2. Or edit config directly

Add to the repo root's .mcp.json (create it if missing) — this keeps the server scoped to this repo:

{
  "mcpServers": {
    "mtel-skill-resolver": {
      "type": "http",
      "url": "https://mcp-registry.internal.company.com/mcp"
    }
  }
}

3. Verify

claude mcp list        # shows mtel-skill-resolver ✓ Connected

Inside Claude Code, the resolve_skills tool is now available. The init-project flow will call it automatically when detecting your tech stack.

The resolver is stateless — no login/session required beyond the optional bearer token. Health check: GET /health.
